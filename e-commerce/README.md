# Frontend Storeku (React + Vite)

Frontend aplikasi e-commerce Storeku yang dibuat menggunakan React dan Vite.

## Cara Menjalankan
1. Install dependensi:
   ```bash
   npm install
   ```
2. Jalankan aplikasi:
   ```bash
   npm run dev
   ```

Aplikasi bisa dibuka di browser pada alamat `http://localhost:5173`.
Frontend terhubung ke backend NestJS di `http://localhost:3000`.
